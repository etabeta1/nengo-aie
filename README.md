# Nengo-AIE

A [nengo](https://www.nengo.ai) backend that runs on XDNA NPUs.

## Installation

- Follow the setup instructions at [Xilinx/mlir-aie](https://github.com/Xilinx/mlir-aie)
- Clone this repository
- `hatch build`
- `pip install dist/*.whl`

> Please note that this package is tested with [Xilinx/mlir-aie](https://github.com/Xilinx/mlir-aie) commit ce9af0f130a550e6355b655879214fd7283a016a
